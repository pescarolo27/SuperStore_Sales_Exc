# Super Store Sales (Excel)

**The Data:** The Superstore Sales data provides sales data for a fictional retail company, including information on products, orders and customers ([Hackernoon](https://hackernoon.com/15-excel-datasets-for-data-analytics-beginners)). 
The Excel file contains sheets regarding notes about the datasets, the original datasets, modified versions of the datasets, analyses, & a final dashboard ("Dashboard 1").

**Purpose:** An Excel dashboard was created to display relevant metrics according to the variables involved such as sales, products, & more.
